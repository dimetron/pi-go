# AGENTS.md

> `kbx-gateway` is a Kubernetes-native AI gateway: a Go control plane that programs Envoy, plus a TypeScript dashboard. Production-used by 2 telco tenants; breaking changes require an RFC.

## Quick start

```bash
make dev-setup          # installs tools, pulls images
make build              # builds control plane + dashboard
make test               # unit + integration
make run                # kind cluster + gateway + dashboard at :8080
```

## Repository layout

```
cmd/            # Go entrypoints (gateway, cli)
internal/       # Go control plane — not importable externally
pkg/            # Public Go API (semver-stable)
api/v1alpha1/   # CRDs — generated, edit markers not Go
web/            # TypeScript dashboard (Vite + React)
deploy/         # Helm chart, kustomize overlays
docs/           # Architecture, RFCs, runbooks
hack/           # Dev scripts — not shipped
```

## Conventions

- Commits: Conventional Commits (`feat:`, `fix:`, `chore:`...). Scope is the top-level dir.
- PRs: squash-merge, title becomes the commit. Link the Linear KBX-### issue.
- Branches: `feat/kbx-123-short-slug`.
- Every exported Go symbol needs a doc comment; every React component is a named export.

## Do not touch

- `api/v1alpha1/zz_generated_*.go` — regenerated by `make generate`
- `web/src/gen/` — OpenAPI client, regenerated
- `vendor/` — run `go mod tidy && go mod vendor`
- `deploy/crds/` — mirror of `api/`, updated by `make manifests`

## Testing policy

- New packages require table-driven tests. PRs that drop coverage below 70% are blocked.
- Integration tests live in `test/e2e/` and need `make kind-up` first.
- Run a single Go test: `go test ./internal/reconciler -run TestReconcile_Deletes -v`
- Run a single TS test: `pnpm --filter web test -- dashboard.test.tsx`

## Gotchas

- `KUBECONFIG` must point at the kind cluster from `make kind-up`, not your prod context.
- `make generate` must be run after any change to `api/v1alpha1/*_types.go` or CI will fail.
- The dashboard proxies `/api` to `:9090` in dev — if you see CORS errors, the control plane isn't running.
- Envoy xDS snapshots are cached for 30s; set `GATEWAY_XDS_TTL=0` to disable during debugging.

## Go

- Toolchain: Go 1.24 (see `go.mod`)
- Module: `github.com/kubex/kbx-gateway`
- Build: `go build ./...`
- Test: `go test ./...` — single: `go test ./internal/foo -run TestName -v`
- Race: `go test -race ./...` (required in CI)
- Lint: `golangci-lint run` — config in `.golangci.yml`, v2 format
- Format: `gofmt -s -w . && goimports -local github.com/kubex -w .`
- Deps: `go mod tidy` after any import change; commit `go.sum`
- Errors: wrap with `fmt.Errorf("reconcile %s: %w", name, err)`; check with `errors.Is/As`
- Logging: `log/slog` with `slog.Default()`; never `fmt.Println` in non-cmd code
- Context: `ctx context.Context` is always the first argument
- Concurrency: prefer `errgroup.WithContext`; no bare goroutines in reconcilers

## TypeScript

- Package manager: **pnpm** (do not use npm or yarn — lockfile will break)
- Node: 22 LTS (see `.nvmrc`)
- Install: `pnpm install --frozen-lockfile`
- Build: `pnpm --filter web build`
- Test: `pnpm --filter web test` (Vitest) — single: `pnpm --filter web test -- <pattern>`
- Lint: `pnpm --filter web lint` (ESLint flat config)
- Typecheck: `pnpm --filter web typecheck`
- Format: `pnpm --filter web format` (Prettier)
- `tsconfig.json` is strict — do not add `// @ts-ignore`; use `// @ts-expect-error` with a reason
- Imports: use `@/` alias from `tsconfig.json`, not `../../../`
