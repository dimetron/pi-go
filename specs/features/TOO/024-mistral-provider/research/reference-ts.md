### Reasoning mapping (streamSimple, mistral-conversations.ts:115-136)

- `clampThinkingLevel` walks `["off","minimal","low","medium","high","xhigh","max"]`
  against model's supported levels; "off" → undefined (no reasoning control).
- `usesReasoningEffort(model)`: only `mistral-small-2603`, `mistral-small-latest`,
  `mistral-medium-3.5` → get `reasoning_effort`.
- `usesPromptModeReasoning(model)`: `model.reasoning && !usesReasoningEffort(model)`
  → get `prompt_mode: "reasoning"`.
- `mapReasoningEffort`: `model.thinkingLevelMap?.[level] ?? "high"` — so "medium"
  → "high" (Mistral's only non-"none" effort). Wire: `payload.reasoningEffort`,
  `payload.promptMode` set in buildChatPayload (260-262).

## 2. prompt_cache_key / caching

- `if (shouldUsePromptCaching(options)) payload.promptCacheKey = options.sessionId;`
  (line 263). `shouldUsePromptCaching` = `options?.cacheRetention !== "none" && !!options?.sessionId`.
- Dual-channel: body `prompt_cache_key = sessionId` **and** request header
  `x-affinity = sessionId` for KV-cache reuse (lines 232-236).
- Cached-token accounting: `getMistralCachedPromptTokens` reads
  `promptTokensDetails.cachedTokens` / `prompt_tokens_details.cached_tokens` /
  `promptTokenDetails.cachedTokens` / `numCachedTokens` / `num_cached_tokens`,
  clamps to [0, promptTokens]; `usage.input = promptTokens - cached`,
  `usage.cacheRead = cached`.

## 3. Thinking content

- **Mistral does NOT use delta.reasoning / reasoning_content.** Thinking arrives
  as content chunks: `delta.content` items with `type: "thinking"`, each carrying a
  `thinking: [{type:"text", text}]` array. The code concatenates part texts and
  pushes ThinkingContent blocks with thinking_start/delta/end events.
- Replay (outbound assistant): converts ThinkingContent back to
  `{type:"thinking", thinking:[{type:"text",text}]}`.
- CHANGELOG: "Switched the Mistral provider from the OpenAI-compatible completions
  path to Mistral's native SDK and conversations API, preserving native thinking
  blocks" (#1716). Usage.reasoning token counts not populated for Mistral.

## Tool call ID normalization

- `MISTRAL_TOOL_CALL_ID_LENGTH = 9`.
- `createMistralToolCallIdNormalizer`: idempotent map; incoming ID → alphanumeric
  only; if len==9 keep, else `shortHash(seed).replace(non-alnum).slice(0,9)`;
  collision handled with attempt++.
- Applied only to replayed tool call IDs from **other models** (transform-messages
  normalizes when `!isSameModel`). Incoming stream tool calls: keep id, else
  derive from index.
